# NyayaSetu

Indian case-law research desk for advocates. Paste facts, search Supreme Court and High Courts, and get a memo with issues, doctrines, and citations.

**Not legal advice** — research assistance only. Verify every citation on the original judgment.

## Sign in

- Continue with Google
- Continue with X
- Email or username + password (register once)

Each account keeps its own Past memos.

## Run

```bash
npm install
npm run dev
```

Open the app, sign in, paste case facts, and start research. UI defaults to English; switch to Hindi with **हि**.
