# Format guides (English only)

Full paste: [paste-bank.md](paste-bank.md). Bot rules: [bot-workflow.md](bot-workflow.md).

## X
- Exact paste ≤ 280 chars per row  
- Threads = one row per tweet (PB-X-02a–e)  
- Media: `public/og.jpg` only  

## Article
- Share `/story`; don’t invent a second origin myth  

## WhatsApp status
- Human posts by default  
- Short beat preferred  

## Marketing
- Bios / LinkedIn / landing from PB-MKT-*  
- If pricing mentioned: card not live  

## Replies
- Match trigger → PB-RPL-* Exact paste  
- No dunking on GoI products  

## Personal messages / Outreach email
- Replace `{Name}`  
- Default Bot mode = Human only  
- Subject line is first `Subject:` line for emails  

## Approve checklist
- [ ] EN only  
- [ ] Exact paste final  
- [ ] Claim level honest  
- [ ] Preflight OK  
- [ ] Bot mode intentional  
- [ ] Vineet Approved before Bot may post
